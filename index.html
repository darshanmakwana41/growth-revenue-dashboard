Partner Type Review

a pattern across the platform's four partner types — not a judgement on any single partner

Capture varies by partner type, not by effort

PAF / PAR / SAR / SAD are the four partner types the platform records. The spread between them is wide enough to be structural — worth a conversation with the commercial team about how each type is incentivised on fuel, not a reason to single out any one partner.

The same type produces very different outcomes

Two partners of the same type can sit at 0% and 85% capture. So the type sets the odds, but does not decide the outcome — individual partners still vary a lot within it.
